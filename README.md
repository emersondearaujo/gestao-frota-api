# Sistema de Gestão de Frota

Projeto desenvolvido com Java + Spring Boot + React.

## Funcionalidades
- Cadastro de caminhões
- Cadastro de motoristas
- Cadastro de rotas
- Criação de fretes
- Controle de status
- Cálculo automático de frete

## Tecnologias
- Java 17
- Spring Boot
- React
- Axios
- H2 Database
